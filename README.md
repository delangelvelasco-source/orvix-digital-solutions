## Instrucciones de limpieza de caché

Si los cambios no se reflejan (especialmente la esfera 3D), limpia la caché del navegador:

### Safari (iPhone / Mac)
1. Ve a **Ajustes → Safari**
2. Baja hasta **Borrar historial y datos de sitios web**
3. Confirma
4. Cierra Safari completamente (desliza hacia arriba desde el selector de apps)
5. Vuelve a abrir el enlace

### Chrome (Android / Desktop)
1. Toca los **tres puntos** (menú)
2. **Historial → Borrar datos de navegación**
3. Selecciona **Imágenes y archivos en caché**
4. Borra
5. Recarga la página

### Chrome Desktop (atajo)
- **Windows/Linux**: `Ctrl + Shift + R`
- **Mac**: `Cmd + Shift + R`

### Firefox
1. Menú → **Ajustes → Privacidad y seguridad**
2. **Cookies y datos del sitio → Limpiar datos**
3. Marca solo **Contenido web en caché**
4. Limpia y recarga
